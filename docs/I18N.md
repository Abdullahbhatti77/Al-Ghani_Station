# Internationalisation

PumpHisab supports **English** (`en`) and **Roman Urdu** (`ur`, Urdu written in Latin letters). Urdu script is not used.

## Files
`src/lib/i18n/`
- `en.ts`, `ur.ts`: base dictionaries. They also merge in the module files:
- `shifts.*.ts`, `inventory.*.ts`, `finance.*.ts`, `mvp.*.ts`
- `index.tsx`: `I18nProvider`, `useT()`, `translate()`

`TranslationKey` comes from the English dictionary, and `ur` is typed as `Record<TranslationKey, string>`. A missing Roman Urdu key is therefore a type error.

## Usage
```tsx
const { t } = useT();
<h1>{t("nav.dashboard")}</h1>            // "Dashboard" / "Aaj ka Khulasa"
t("some.key", { amount: "Rs 500" })      // replaces {amount}
```
All visible text must use keys. Do not hardcode strings.

## Selecting and persisting language
`LanguageSelect` (`src/components/common/language-select.tsx`) sets the language and stores it in `localStorage` under `pumphisab.lang`. When signed in, it also saves it to `profiles.preferred_language`. The `<html lang>` is set to `en` or `ur-Latn`.

## Adding a key
1. Add it to the relevant `*.en.ts` file.
2. Add the Roman Urdu text to the matching `*.ur.ts` file.
3. Run `bun run test`.

## Checks
`src/lib/i18n/i18n.test.ts` checks that both dictionaries have the same keys, that neither contains Arabic/Urdu script, and that the agreed terms are used:

| English | Roman Urdu |
|---|---|
| Dashboard | Aaj ka Khulasa |
| Close Shift | Shift Band Karein |
| Fuel Stock | Fuel ka Stock |
| Expenses | Kharchay |
| Save | Mehfooz Karein |
| Cancel | Wapas |
